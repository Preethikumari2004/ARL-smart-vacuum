💡 How It Works

Agent The vacuum cleaner that makes decisions
Environment The grid room with dirty cells and obstacles
State Vacuum position + which cells are still dirty
Action UP · DOWN · LEFT · RIGHT · CLEAN
Reward +10 clean dirt · +20 finish room · −5 hit wall
Q-Table Stores expected reward for every (state, action) pair
Episode One full cleaning attempt from start to finish
Exploration ε-greedy: try random actions to discover new strategies
Exploitation Use the best known action from Q-table
Q-Learning Update Rule Q(s,a) ← Q(s,a) + α[r + γ·max Q(s',a') − Q(s,a)]
